# Privacy Policy – Clipadores

Last updated: November 20, 2026

Clipadores ("the App") is a personal desktop tool used only by its owner.

- **Data accessed:** with the user's permission (TikTok Login Kit), the App receives an access token and the basic
  account identifier (open_id) of the user's own TikTok account, only to upload videos as drafts (scope
  `video.upload`) and to read the upload status.
- **Storage:** the token is stored only on the owner's own computer. Nothing is sent to any server other than TikTok's
  official API.
- **Sharing:** no data is sold, shared or used for advertising.
- **Removal:** the user can revoke access at any time in the TikTok app (Settings > Security > Manage app permissions)
  and delete the local file to erase all stored data.
- **Contact:** cityv9179@gmail.com

# Política de Privacidade – Clipadores

Ferramenta pessoal, usada só pelo dono. Com a permissão do usuário, ela recebe um token de acesso e o identificador
básico da própria conta do TikTok, apenas para enviar vídeos como rascunho e ver o status do envio. O token fica salvo
só no computador do dono e nada é enviado a outros servidores além da API oficial do TikTok. Nenhum dado é vendido ou
compartilhado. Dá para revogar o acesso a qualquer momento no app do TikTok (Configurações > Segurança > Permissões de
apps). Contato: cityv9179@gmail.com
